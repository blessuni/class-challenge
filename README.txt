우리 반 오늘의 도전 - 공개 시연용 앱

1. index.html을 브라우저에서 열면 바로 실행됩니다.
2. 오른쪽 위 '교사용 설정'에서 반 이름, 유아 수, 유아 이름(한 줄에 한 명씩), 활동 제목, 안내 문구, 성공 문구를 수정할 수 있습니다.
3. 설정 저장 후 아이 화면으로 돌아가 이름 버튼을 눌러 시연합니다.
4. 이 시연용 앱은 실제 다이아몬드반 앱과 분리되어 있으며, Netlify 서버나 기존 앱의 기록과 연결되지 않습니다.
5. 입력한 명단과 기록은 현재 기기의 브라우저(localStorage)에만 저장됩니다. 다른 기기와 실시간 공유되지 않습니다.

Netlify 배포: 이 폴더의 index.html을 포함한 파일을 GitHub 저장소에 올리고 Netlify에서 해당 저장소를 배포하면 됩니다. 별도 빌드 명령은 필요하지 않습니다.
